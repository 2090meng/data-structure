使用说明（第一次请先看这里） How to use (read this first)
  1. 先在右上角选择语言。Pick a language at the top-right.
  2. 在左侧选择数据结构：数组 Array、链表 Linked List、栈 Stack、队列 Queue、二叉树 Binary Tree（切换结构会重置内存并载入对应示例代码）。Choose a data structure: Array, Linked List, Stack, Queue or Binary Tree (switching rebuilds the memory and loads a matching sample).
  3. 选择操作：数组为插入/删除/修改/查找；链表为插入/删除/查找/头插法/尾插法；栈为入栈/出栈/取栈顶/查找；队列为入队/出队/查看队头/查找；二叉树为插入左/右孩子、删除子树、查找、先序/中序/后序/层次遍历。Pick an operation: array = insert/delete/set/search; linked list = insert/delete/search/head-insert/tail-insert; stack = push/pop/peek/search; queue = enqueue/dequeue/front/search; binary tree = insert left/right child, delete subtree, search, preorder/inorder/postorder/level-order traversal.
  4. 填参数：插入/删除/修改填「位序」（按考研教材从 1 开始；插入可取 1..length+1，删除/修改可取 1..length），插入/修改/查找/入栈/入队填「值」（栈和队列不需要填位序；链表的头插法/尾插法只需填「值」，无需位序）；二叉树的插入左/右孩子填「父结点位序」与「值」，删除填「子树根结点位序」，遍历无需输入。Fill parameters: position for insert/delete/set (1-based per textbook; insert allows 1..length+1, delete/set allows 1..length), value for insert/set/search/push/enqueue (stack and queue need no position); for the binary tree, insert left/right takes the parent index and value, delete takes the subtree root index, traversal needs no input.
  5. 指针语义按教材：栈的 top 指向栈顶元素的下一个空位（入栈先写入 S.data[S.top]，再 S.top++；出栈先 S.top--，再取数据）；队列为循环队列且牺牲一个单元（rear 指向队尾的下一个空位，front==rear 为空，(rear+1)%MaxSize==front 为满，最多存 MaxSize-1 个）。Pointer conventions follow the textbook: stack top points to the next free slot (push writes S.data[S.top] then S.top++; pop does S.top-- then reads); queue is a circular queue sacrificing one slot (rear points to the slot after the last element, empty when front==rear, full when (rear+1)%MaxSize==front, storing at most MaxSize-1).
  6. 链表为【带头结点】的单链表：head 指向头结点，块内左栏是 data、右栏是 next（后继结点地址或 NULL），块间箭头就是 next 指针；每个结点单独分配，所以地址不连续。插入先 s->next = p->next 再 p->next = s；删除时 p->next = q->next 后结点被摘链，内存不回收，灰显在行尾。头插法：s->next = L->next; L->next = s;，新结点直接成为第 1 个结点（O(1)），连续头插会得到与输入相反的顺序；尾插法：p = L; while (p->next) p = p->next; s->next = NULL; p->next = s;，先找表尾再挂接（O(n)），顺序与输入一致。代码模式还可用 buildHead / buildTail 按序列建表。The linked list has a head node: head points to it, each block shows data and next (address of the successor or NULL), and arrows are the next pointers; nodes are allocated separately, so addresses are non-contiguous. Insert does s->next = p->next then p->next = s; delete does p->next = q->next, the node is unlinked but its memory is kept (shown greyed at the end). Head insert: s->next = L->next; L->next = s; makes the new node the 1st one in O(1), so repeated head inserts reverse the input order; tail insert: p = L; while (p->next) p = p->next; s->next = NULL; p->next = s; walks to the last node first (O(n)) and keeps the input order. Code mode also supports buildHead / buildTail to build a list from a sequence.
  7. 二叉树为【二叉链表】：每个结点单独分配（地址不连续），块间的箭头表示 lchild / rchild 指针。结点按【层序编号】定位：根为第 1 号，第 i 号的左孩子为 2i、右孩子为 2i+1。空树时“插入左/右孩子”会建立根结点；删除会移除以该结点为根的整棵子树（内存不回收，灰显在下方）。查找按先序逐个比较，遍历按先序/中序/后序/层次输出访问序列。The binary tree uses a linked representation: every node is allocated separately (non-contiguous addresses), and the arrows are lchild / rchild pointers. Nodes are addressed by level-order numbering: root = 1, left child of node i = 2i, right child = 2i+1. When the tree is empty, Insert Left/Right creates the root; Delete removes the whole subtree rooted at that node (memory is kept and greyed below). Search compares nodes in preorder; traversals output the preorder/inorder/postorder/level-order sequence.
  8. 点「执行」立即运行动画查看结果；代码模式点「运行代码」后，用「单步执行」逐行或「自动播放」连续播放。Click "Execute" to run the animation right away; in code mode, click "Run Code" then "Step" line by line or "Play" to auto-run.
  9. 也可在「代码驱动」区输入伪代码，点「运行代码」后逐行高亮执行，右侧内存同步变化。Or type pseudo-code in the code area and click "Run Code" — it highlights each line while the memory updates.
  10. 若粘贴的是完整 C 代码，先点「提取指令」：它会自动过滤 #include、printf、for/while/if 等无关代码，只保留初始化、赋值、插入、删除、交换、查找、入栈出栈、入队出队等可演示操作，并把清洗后的指令回填到输入框；再点「运行代码」即可演示。If you paste full C code, click "Extract" first: it strips #include, printf, for/while/if and other irrelevant code, keeps only demonstrable operations (init, assignment, insert, remove, swap, search, push/pop, enqueue/dequeue), and writes the cleaned commands back into the box; then click "Run Code" to play.
  11. 观察右侧内存块的地址与值变化，配合下方日志理解每一步。Watch the memory block addresses/values on the right, with the log below.
  12. 点「重置」清空并恢复初始状态。Click "Reset" to clear and restart.

支持 C/C++ 风格（大小写不敏感，// 注释，; 分隔；#include、printf、for 等会被忽略）： int arr[10] = {10, 20, 5}; 声明并初始化； arr[1] = 20; 修改（C 物理下标，0 起始）；insert(arr, 2, 5); 在第 2 个位置插入（位序 1 起始）； push(arr, 7); 入栈；pop(arr); 出栈； enqueue(q, 7); 入队；dequeue(q); 出队； remove(arr, 1); 删除第 1 个（位序）；search(arr, 5); 查找； 链表同样用位序：insert(L, 1, 5); 插到头结点之后，remove(L, 2); 删除第 2 个结点；头插法 insertHead(L, 5);、尾插法 insertTail(L, 99);，按序列建表 buildHead(L, 10, 20, 30);（结果 30→20→10）/ buildTail(L, 10, 20, 30);（结果 10→20→30）； 二叉树按层序编号：int T[15] = {10, 20, 30}; 按层序建树，insertLeft(T, 2, 5); 给第 2 号结点挂左孩子，insertRight(T, 2, 6); 挂右孩子，remove(T, 2); 删除子树，preorder(T); / inorder(T); / postorder(T); / levelorder(T); 四种遍历； 简写可省略变量名：set(2, 99);（物理下标）、insert(2, 99);（位序）、remove(1);（位序）、swap(1, 3);（物理下标）。
C/C++-style (case-insensitive, // comments, ; separator; #include, printf, for etc. are ignored): int arr[10] = {10, 20, 5}; declare & initialize; arr[1] = 20; set (C physical index, 0-based); insert(arr, 2, 5); insert at position 2 (1-based); push(arr, 7); push; pop(arr); pop; enqueue(q, 7); enqueue; dequeue(q); dequeue; remove(arr, 1); delete element 1 (1-based); search(arr, 5); search; linked list also uses 1-based positions: insert(L, 1, 5); inserts after the head node, remove(L, 2); deletes node 2; head insert insertHead(L, 5);, tail insert insertTail(L, 99);, build from a sequence buildHead(L, 10, 20, 30); (yields 30→20→10) / buildTail(L, 10, 20, 30); (yields 10→20→30); binary tree uses level-order numbering: int T[15] = {10, 20, 30}; builds by level order, insertLeft(T, 2, 5); attaches a left child to node 2, insertRight(T, 2, 6); a right child, remove(T, 2); deletes the subtree, preorder(T); / inorder(T); / postorder(T); / levelorder(T); four traversals; shorthand (variable omitted): set(2, 99); (physical index), insert(2, 99); (position), remove(1); (position), swap(1, 3); (physical index).
