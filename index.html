数据结构内存动态演示 Data Structure Memory Visualizer

使用说明（第一次请先看这里） How to use (read this first)
  1. 先在右上角选择语言。Pick a language at the top-right.
  2. 在左侧选择数据结构（目前仅「数组 Array」可用）。Choose a data structure (only Array is available for now).
  3. 选择操作：插入(Insert)、删除(Delete)、修改(Set)、查找(Search)。Pick an operation: insert, delete, set, or search.
  4. 填参数：插入/删除/修改填「下标」，插入/修改/查找填「值」。Fill parameters: index for insert/delete/set, value for insert/set/search.
  5. 点「执行」立即运行动画查看结果；代码模式点「运行代码」后，用「单步执行」逐行或「自动播放」连续播放。Click "Execute" to run the animation right away; in code mode, click "Run Code" then "Step" line by line or "Play" to auto-run.
  6. 也可在「代码驱动」区输入伪代码，点「运行代码」后逐行高亮执行，右侧内存同步变化。Or type pseudo-code in the code area and click "Run Code" — it highlights each line while the memory updates.
  7. 观察右侧内存块的地址与值变化，配合下方日志理解每一步。Watch the memory block addresses/values on the right, with the log below.
  8. 点「重置」清空并恢复初始状态。Click "Reset" to clear and restart.
