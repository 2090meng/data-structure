    快速上手Quick start

    1. 在顶部标签选择结构，左侧选择操作并填参数，点「执行」。 Pick a structure tab, choose an action and fill in the parameters, then click Execute.
    2. 用「单步执行 / 自动播放 / 上一步」逐步观察，速度可调。 Inspect step by step with Step / Play / Back; the speed is adjustable.
    3. 在底部「代码驱动」标签页写伪代码，点「运行代码」后逐行高亮。 Write pseudo-code in the Code tab and click Run Code to highlight each line.
    4. 粘贴完整 C 代码时先点「提取指令」，自动过滤 #include、printf、for 等无关代码后再运行。 For full C code, click Extract first: #include, printf, for etc. are filtered out before running.

    参数与指针语义Parameters & pointer conventions

    • 位序从 1 开始：插入取 1..length+1，删除/修改取 1..length；栈、队列、链表头插/尾插只需填值。 Positions are 1-based: insert 1..length+1, delete/set 1..length; stack, queue and head/tail insert need only a value.
    • 栈的 top 指向栈顶的下一个空位；队列为循环队列并牺牲一个单元；链表带头结点、结点地址不连续。 Stack top points to the next free slot; the queue is circular and sacrifices one slot; the linked list has a head node with non-contiguous addresses.
    • 二叉树按层序编号：根为第 1 号，第 i 号的左孩子为 2i、右孩子为 2i+1。 Binary tree uses level-order numbering: root = 1, left child of i = 2i, right child = 2i+1.
