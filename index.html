数据结构内存动态演示 Data Structure Memory Visualizer

使用说明（第一次请先看这里） How to use (read this first)
  1. 先在右上角选择语言。Pick a language at the top-right.
  2. 在左侧选择数据结构（目前仅「数组 Array」可用）。Choose a data structure (only Array is available for now).
  3. 选择操作：插入(Insert)、删除(Delete)、查找(Search)。Pick an operation: insert, delete, or search.
  4. 填参数：插入/删除填「下标」，插入/查找填「值」。Fill parameters: index for insert/delete, value for insert/search.
  5. 先点「执行」生成动画步骤，再点「单步执行」逐帧看，或点「自动播放」连续播放。Click "Execute" to generate steps, then "Step" to advance one by one, or "Play" to auto-run.
  6. 观察右侧内存块的地址与值变化，配合下方日志理解每一步。Watch the memory block addresses/values on the right, with the log below.
  7. 点「重置」清空并恢复初始状态。Click "Reset" to clear and restart.
